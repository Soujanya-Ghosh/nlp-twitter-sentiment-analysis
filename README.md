# Twitter Sentiment Analysis
This project predicts tweet sentiment using NLP and Machine Learning.

 ***** Features
- Text preprocessing
- TF-IDF vectorization
- Logistic Regression
- Naive Bayes
- SVM Classifier
- WordCloud visualization
- Confusion Matrix
- Streamlit Web App

***** Technologies Used
- Python
- Scikit-learn
- NLP
- Streamlit
